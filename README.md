# How to Get a .CSV File

## Step 1: Download Historical Data from the Dashboard. 
  1- Navigate to the dashboard where you can access historical data.  
  2- Look for the option to download data, often labeled as "Download"   
  3- Click the download button and save the file to your local machine.

![image](https://github.com/user-attachments/assets/245f07ae-74f7-4ee8-bd70-c5e59c6a03ed)

## Step 2: Copy the .CSV File
  1- Locate the downloaded .csv file in your downloads folder.
  2- Copy the .csv file to your clipboard

![image](https://github.com/user-attachments/assets/3260ea62-4d24-4d7c-b8a7-bf9b582f9edb)

## Step 3: Prepare the Python Script Folder  
  1- Open the python_script folder on your computer.
  2- Ensure that this folder is empty except for the  `main.py` file. If there are other files, move or delete them to keep it clean.
  3- Paste the copied .csv file into the python_script folder

### Step 4: Run the Python Script
  1- Run the Python script by double-clicking on `run_main.bat `.
  2- After successful execution, the script will generate a new file named `update_file.csv` in the same folder.
